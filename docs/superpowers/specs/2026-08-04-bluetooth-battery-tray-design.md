# 蓝牙电量托盘监控设计

## 目标

为 Windows 11 提供一个常驻系统托盘的轻量应用。托盘图标使用电池外形直观表示蓝牙设备的大致电量；鼠标悬停时显示设备名称和精确电量；用户通过托盘右键菜单配置监控设备和展示模式。

## 支持范围

- 使用 .NET 10 和 WinForms。
- 读取 Windows 设备 API 已公开的蓝牙连接状态及电量。
- Windows 设置能够显示电量的设备属于首版支持范围。
- 已连接但系统未公开电量的设备显示“电量未知”。
- 发布为 `win-x64` 自包含单文件，用户无需安装 .NET 运行时。

## 非目标

- 不适配耳机、手柄等设备的厂商私有电量协议。
- 不提供独立设置窗口。
- 不提供安装器、开机自启或低电量通知。
- 不复制 RunCat365 的动画、资源或实现代码，仅参考其轻量托盘应用形态。

## 运行结构

应用不创建主窗口，由一个 WinForms `ApplicationContext` 管理生命周期：

1. `BluetoothMonitor` 每 60 秒枚举蓝牙设备并读取连接状态和电量。
2. `TrayController` 根据当前配置选出应展示的设备，更新托盘图标、悬停文本和右键菜单。
3. `SettingsStore` 使用 `System.Text.Json` 在 `%LocalAppData%\TrayMonitor\settings.json` 保存配置。
4. 单实例互斥锁阻止重复启动产生多个托盘图标。

不引入第三方运行时依赖。

## 数据模型

每台设备保留以下信息：

- Windows 设备 ID，用于稳定匹配配置。
- 显示名称。
- 是否已连接。
- 电量百分比；系统未提供时为空。

配置保存：

- 展示模式：`Primary`、`Lowest` 或 `Cycle`。
- 已勾选的监控设备 ID。
- 主设备 ID。

首次运行默认监控全部已连接设备，并使用 `Lowest` 模式。已配置设备断开后仍保留在配置中。

## 展示模式

- `Primary`：图标显示用户指定主设备的电量。
- `Lowest`：图标显示所有已勾选且电量已知的已连接设备中的最低电量。
- `Cycle`：每 5 秒切换一台已勾选且已连接的设备；设备列表仍按 60 秒刷新。

当所选模式没有可展示设备、蓝牙关闭或读取失败时，显示未知状态图标。

## 图标与悬停信息

电池图标在内存中按五档绘制，避免维护多套图片资源：

- 0-20%：红色，1 档填充。
- 21-40%：黄色，2 档填充。
- 41-60%：黄色，3 档填充。
- 61-80%：绿色，4 档填充。
- 81-100%：绿色，5 档填充。
- 未知：灰色问号电池。

悬停文本列出已勾选设备的名称和精确百分比。轮播模式下，当前设备排在首行。文本超过 Windows `NotifyIcon` 限制时按完整设备条目截断，避免截断到半个名称或百分比。

## 右键菜单

右键菜单直接承载全部配置：

- “显示模式”子菜单：主设备、最低电量、轮播，使用单选状态。
- “监控设备”子菜单：设备列表，使用复选状态。
- “主设备”子菜单：设备列表，使用单选状态。
- “立即刷新”。
- “退出”。

菜单打开前根据最新设备快照重建。模式或设备选择变更后立即保存，无“应用”按钮。

## 错误处理

- 刷新使用非重入保护，上一轮未完成时跳过本轮。
- 单个设备缺少电量时仅标记该设备未知，不影响其他设备。
- 整体枚举失败时保留应用运行，显示读取失败状态，并在下一周期重试。
- 配置文件缺失或 JSON 无效时使用默认配置；后续保存覆盖为有效配置。
- 退出时显式隐藏并释放 `NotifyIcon`，避免残留托盘图标。

## 验证

自动检查覆盖纯逻辑：

- 三种模式的设备选择结果。
- 最低电量计算忽略断开和未知电量设备。
- 轮播顺序及设备列表变化后的索引修正。
- 百分比到五档图标的映射。
- 配置保存和恢复。

Windows 11 手工验收覆盖：

- 蓝牙开启和关闭。
- 支持设备的连接、断开和电量变化。
- 三种展示模式及右键菜单配置。
- 悬停文本与图标一致。
- 应用重启后配置恢复。
- 第二次启动不会出现额外托盘图标。

## 完成标准

在 Windows 11 上启动发布产物后，应用仅显示一个托盘图标；能发现系统已连接的蓝牙设备；对 Windows 已公开电量的设备显示正确百分比和对应电池档位；三种展示模式及设备选择可通过右键菜单配置并在重启后保持。
