# EXE 电池图标设计

## 目标

为 TrayMonitor 的 Windows 可执行文件嵌入自定义电池图标，使资源管理器、快捷方式和文件属性显示明确的应用标识。

## 图标样式

- 透明背景。
- 深色电池外框和正极端子，延续现有托盘电池图标的几何风格。
- 电池内部使用黄色填充约 50%，表示半电量。
- 图标保持静态；运行时托盘图标继续根据设备电量动态变化。

## 资源格式

新增一个多分辨率 Windows ICO 文件，至少包含 16、24、32、48、64、128 和 256 像素的方形图像。各尺寸单独按像素网格绘制，避免由单个 32 像素图像放大造成模糊。

项目通过 MSBuild 的 `ApplicationIcon` 属性嵌入该 ICO，不新增运行时依赖，也不在启动时加载图标文件。

## 验证

- 自动检查 ICO 文件头、图像数量和要求的尺寸集合。
- Release 构建必须保持零警告、零错误。
- 从构建后的 EXE 提取关联图标，确认它不是空资源。
- 重新发布 `win-x64` 自包含单文件，并确认 ProductVersion 对应最终提交。

## 非目标

- EXE 图标不随蓝牙设备电量变化。
- 不修改托盘动态图标的颜色、档位或刷新逻辑。
- 不引入图像生成库、安装器或图标主题配置。
